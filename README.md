## 📖 About The Project
**Jaws Burger** is a lightweight, website-based catalog and dashboard developed to elevate the digital branding of a local culinary UMKM. Designed with a focus on customer engagement and easy maintenance, this platform serves as an interactive digital storefront. To keep operational costs minimal and data management simple for the business owners, the system creatively utilizes an Excel-based API as its content management system (CMS) and database.

## ✨ Key Features
* **🏢 Business Profile:** A dedicated section detailing the brand's identity, vision, and story to build customer trust.
* **📋 Dynamic Pricelist (Excel-Powered):** An easily updatable menu catalog where prices and items are fetched directly from an Excel/Spreadsheet API.
* **📸 Customer Gallery:** A visual showcase of products and customer experiences to strengthen digital branding.
* **🛒 Direct Ordering Link:** Seamless routing integration that directs customers straight to the ordering channel (e.g., WhatsApp or delivery apps) for quick transactions.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Database / API:** Excel Spreadsheet API (Data fetching & state management)
* **UI/UX Design:** Figma
